# Playwright Automation Testing Portfolio

Automation testing project using Playwright with JavaScript.

## Website Under Test
https://www.saucedemo.com

## Tools & Technology
- Playwright
- JavaScript
- Node.js
- Page Object Model
- HTML Test Report

## Project Structure

playwright-automation-portfolio
│
├── tests
│   ├── login.spec.js
│   ├── cart.spec.js
│
├── pages
│   ├── loginPage.js
│   ├── inventoryPage.js
│
├── playwright.config.js
├── package.json
└── README.md

## Test Scenarios

1. User login with valid credentials
2. User add product to cart
3. User view cart page

## How to Run Test

Install dependencies:

npm install

Run automation test:

npx playwright test

## Test Report

Generate HTML report:

npx playwright show-report
